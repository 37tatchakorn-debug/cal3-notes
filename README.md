# Cal3 บท 4–5

โจทย์ตัวอย่างพร้อมเฉลยละเอียดภาษาไทย แยกตามหัวข้อย่อย พร้อมการค้นหาและบันทึกความคืบหน้าอัตโนมัติในเบราว์เซอร์

**เปิดอ่าน:** https://37tatchakorn-debug.github.io/cal3-notes/

- แสดงหรือซ่อนเฉลย และกรองตามบท หัวข้อ หรือประวัติการอ่าน
- จำข้อที่เคยเปิด ข้อล่าสุด ตัวกรอง และตำแหน่งการอ่าน
- สำรองและนำเข้าความคืบหน้าด้วยไฟล์ JSON
- ดาวน์โหลด `index.html` เพื่อเปิดอ่านออฟไลน์ได้

ความคืบหน้าเก็บในเบราว์เซอร์และอุปกรณ์ที่ใช้ ไม่มีการส่งขึ้นเซิร์ฟเวอร์ หากเปลี่ยนอุปกรณ์ให้ใช้การสำรองและนำเข้าความคืบหน้า
